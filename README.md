# Business Performance Dashboard
## Project Overview
An interactive Business Performance Dashboard created using Microsoft Excel
to analyse revenue, expenses, profit, employees, projects and performance
across different locations and departments.
## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel formulas
## Dashboard Features
- Total Employees
- Total Revenue
- Total Expenses
- Total Profit
- Total Projects
- Revenue by Location
- Profit by Location
- Department-wise Employee Analysis
- Employee Performance Analysis
- Interactive Slicers
